| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

We take the security of autonomous agent infrastructure seriously. If you discover a security vulnerability (such as a sandbox bypass, unhandled credential leakage, or an issue in gate verification):

1. **Do NOT open a public GitHub issue.**
2. Send an advisory report via private GitHub Security Advisory:
   - Navigate to the repository's **Security** tab and click **Report a vulnerability**.
   - Alternatively, contact the maintainers via `umairmsm@users.noreply.github.com`.
3. Please include:
   - A description of the vulnerability and attack vector.
   - A minimal reproduction script or steps.
   - Never print or transmit actual production credentials or tokens in reports.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix.
